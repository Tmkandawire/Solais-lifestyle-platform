# Solaís Lifestyle Platform

Solaís Lifestyle is a modern event, ticketing, and community platform for thoughtfully curated lifestyle experiences.

## Project Vision

To create a modern digital platform through which attendees, vendors, partners, and the Solaís team can connect, manage experiences, purchase tickets, and participate in the growing Solaís community.

## MVP Capabilities

- Marketing website
- Event discovery and management
- Online ticket purchasing
- Online payment integration
- QR-code ticket generation
- Attendee accounts
- Vendor registration and applications
- Partner registration and applications
- Gallery
- Lifestyle Journal
- Contact forms
- Newsletter subscriptions
- Administration dashboard

## Technology Stack

### Frontend

- React
- TypeScript
- Vite
- Tailwind CSS
- Radix UI

### Backend

- Node.js
- Express
- TypeScript
- PostgreSQL
- Prisma ORM
